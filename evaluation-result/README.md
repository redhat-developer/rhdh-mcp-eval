## 📏 Metrics Configured

For this evaluation, every conversation was tested against 3 specific metrics at the **Turn Level**.

### 1. Custom Metrics

* **[`tool_eval`](https://github.com/lightspeed-core/lightspeed-evaluation/blob/main/src/lightspeed_evaluation/core/metrics/custom/custom.py)**: Binary validation of tool calls — exact/regex matching of tool names and arguments against expected tool calls.
* **[`answer_correctness`](https://github.com/lightspeed-core/lightspeed-evaluation/blob/main/src/lightspeed_evaluation/core/metrics/custom/custom.py)**: Response accuracy compared against the expected response, evaluated by the judge panel.

### 2. Ragas Metrics

* **[`faithfulness`](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/faithfulness/)**: Measures whether the response is grounded in the MCP tool result contexts.

**Judge Panel:** `gemini-2.5-pro`, `gpt-4o-mini` (aggregation: max)
